Home DIY Finds

Privacy Policy

Last updated: April 20, 2026

Overview

Home DIY Finds ("the Application") is a personal automation tool used exclusively by its owner to schedule and publish curated affiliate product content to their own Pinterest business account. This Application is not offered as a service to third parties.

Data Collection

The Application does not collect personal data from Pinterest users or the general public. The Application accesses only:

  • Publicly available product information from Amazon.com
  • The owner's own Pinterest business account (via authorized API access)
  • The owner's own Google Drive storage (via authorized API access)

Data Usage

All data accessed is used solely to:

  • Generate and publish pin content to the owner's own Pinterest boards
  • Store generated artifacts temporarily in the owner's own Google Drive
  • Send completion notifications to the owner via Telegram

Data Sharing

The Application does not share, sell, or transmit data to any third party beyond the services necessary for its operation:

  • Pinterest API (for publishing to owner's own boards)
  • Google Drive API (for owner's own storage)
  • Telegram API (for owner's own notifications)

Third-Party Services

This Application interacts with third-party services, each governed by their own privacy policies:

  • Pinterest API — subject to Pinterest's Privacy Policy
  • Amazon Product Pages — via public HTTP access
  • Google Drive API — subject to Google's Privacy Policy
  • Telegram Bot API — subject to Telegram's Privacy Policy

Affiliate Disclosure

As an Amazon Associate, Home DIY Finds earns from qualifying purchases. Product links published on Pinterest may contain affiliate tracking identifiers that attribute purchases to the owner's Amazon Associates account.

User Rights

As this Application is used solely by its owner and does not process data of other users, no user-facing data rights requests apply.

Changes to This Policy

This policy may be updated as the Application's functionality evolves. The "Last updated" date above will reflect any changes.
